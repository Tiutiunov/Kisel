# Kisel architecture

Kisel is a desktop companion for KDE Plasma that watches Claude Code, asks permission on its behalf and chats with Claude. The look, tokens and motion come from the **Kisel design system** (README, `tokens.json`, `motion.md`); this document is only about how the code is organised.

## Stack

| Layer | Choice | Why |
| --- | --- | --- |
| UI | Qt 6.10 Quick (QML), `QtQuick.Shapes`, Controls *Basic* style | The design system already targets Qt 6 / QML. Everything is vector and transform-driven, so it costs ~0 % CPU when idle and renders the same on the software renderer. |
| Logic | C++20, no third-party code | Small, fast to start, one toolchain. |
| Window | `LayerShellQt` (Wayland `wlr-layer-shell`) | An overlay anchored to the top edge, above panels, on KWin. Plain frameless window on X11. |
| Hook relay | `kisel-hook`, a separate tiny C++ binary (POSIX or Win32 + QtCore JSON) | Claude Code starts it for every event; it must start in milliseconds and never block. |
| Secrets | KWallet (`KF6Wallet`) | Keys never touch disk or QML. |
| Tray | `KStatusNotifierItem` | Native on Plasma. |
| Sound | `paplay` (PipeWire), WAVs generated by `scripts/gen_sounds.py` | 10 short bloops, no assets to license. |

## Process and data flow

```
 Claude Code ──hook event (stdin JSON)──▶ kisel-hook ──one JSON line──▶ $XDG_RUNTIME_DIR/kisel.sock
                                              ▲                                   │
                       "allow" | "deny" | silence                           HookServer
                                              │                                   │ HookConnection
                                              └──────────── answer ◀──────── AgentHub ──▶ SessionModel
                                                                                  │  Hub.mood / Hub.permission / Hub.session
                                                                                  ▼
                                                                        QML (Island, views, Mascot)
```

* **Only `PermissionRequest` waits.** `kisel-hook` blocks (≤110 s) for one line from the app and prints Claude Code's documented decision JSON. Every other event is fire-and-forget (≤2 s budget, usually 5 ms).
* **Silence is the safe answer.** If Kisel is closed, slow, crashed, or the user picks "In terminal", the relay prints nothing and Claude Code asks in the terminal as if Kisel were not installed.
* **Answered elsewhere.** If the user answers in the terminal, Claude Code kills the relay, the socket closes, `HookConnection::gone()` fires and the card disappears without sound.

## Modules (`src/core`, no UI dependency, unit-tested)

| File | Responsibility |
| --- | --- |
| `HookServer` | `QLocalServer` on the socket; verifies `SO_PEERCRED` uid; one `HookConnection` per event (line-buffered, 1 MB cap). |
| `AgentHub` | The brain. Event → session state, permission queue, **mood** (`alert` > `happy`/`sad` overrides > `think`/`work` > `sleep` > `idle`), status line, auto-allow rules. QML sees only properties and `allow/deny/always/passToTerminal`. |
| `SessionModel` | `QAbstractListModel` of sessions: steps, current file diff, last command. |
| `HookInstaller` | Merge/remove Kisel's entries in `~/.claude/settings.json`: `preview()` (exact diff + backup path) → `apply()` (dated backup, atomic write). Never touches entries that are not ours; refuses unparsable files. |
| `ChatClient` | Anthropic Messages API, streamed (SSE). Text appears exactly as it streams. Dropped text files are inlined (≤200 KB). |
| `GitHubClient` | One read-only GraphQL request (open PRs + CI state, reviews waiting), token from KWallet, 5-minute poll while the widget is open. |
| `Secrets` | KWallet wrapper, opened lazily (first use may show the unlock dialog). |
| `Preferences` | `~/.config/kisel/kisel.conf`: sound, reduce motion, theme, model, "Always" rules. |
| `Paths` | Every path in one place. The relay repeats `socketPath()` by hand: keep in sync. |

## App shell (`src/app`)

* `IslandWindow` – the platform-specific window code (see "Windows" below for that side). One fixed 708×500 transparent surface; the island animates **inside** it and `setMask()` (= Wayland input region) follows the island, so clicks elsewhere reach other windows and the compositor never resizes a surface mid-animation. Keyboard interactivity is `OnDemand` only while a permission card, the chat or settings is open, so Kisel never steals focus from the terminal.
* **Dragging.** Margins are applied by the compositor a frame late while pointer events keep coming relative to the old position, so moving the surface by the pointer overshoots. While the pointer is down the surface is made as big as the output (`beginGrab`: all four anchors, size 0) and stays still; the island moves inside it by exact pointer coordinates (`setOrigin`), the input region follows the mascot, and on release the surface shrinks back to 708 x 500 at the final margins (`endGrab`). Without layer-shell it falls back to `moveBy` (clamped to the screen).
* **Floating.** The same surface serves both modes. Docked it is anchored to the top edge; floating it is anchored top+left and moved with layer-shell margins (`beginFloat`, `moveBy`, `fitOpen`, `dock`). The input region (`setHitRect`) is the 120 px mascot when closed and the card when open, so the rest of the 708×500 surface stays click-through.
* `Displays` – which output the island lives on (remembered by name, hot-plug aware); `IslandWindow::moveToScreen` re-creates the layer surface on the target output.
* `Sounds` – plays the WAVs through `paplay`/`pw-play` as a plain "Kisel" stream. (Not `media.role=event`: Plasma can mute that whole role.)
* `Launcher` – opens https links only (a pull request).
* `Tray` – StatusNotifierItem (Open, Settings, Quit).
* `main.cpp` – wiring, single-instance probe on the socket, `--demo` (replays a fake session), `--open <view>`, `--grab <png>` (renders one frame and quits; used for development and CI screenshots).

## QML (`qml/`)

* `Theme.qml` mirrors `tokens.json` (dark + light). **Add colours to the design system first, then here.** The mascot uses fixed colours in both themes, like the logo.
* `Mascot.qml` – all ten moods, blink, breathing, spring-following eyes, jump/click squash, dizzy egg, skins. Drawn from the logo's SVG paths.
* `Island.qml` – state machine: collapsed pill ⇄ card, hover open, 600 ms close timer, `holdOpen` rules (permission waiting, drag over, typing, peek), view cross-fade (140 ms), one mascot gliding between slots.
* `HomeView`, `SessionView`, `PermissionView`, `GitHubView`, `ChatView`, `SettingsView` – one file each; `CodePanel` renders diffs and commands.
* Collapsed v2: `PillChip`, `PillBars`, `PillDots`; the mascot's level of detail and mood bridges live in `Mascot.qml`.
* Transitions: `ViewHost` (how each view enters and leaves), `Motion` (stagger helpers), `RollText`, `Assembly` (first launch).
* Components: `KButton` (variants, success move), `StatusPill`, `LaunchTile`, `KToggle`, `KField`, `Toast`.
* Brand-shape motion: `BrandShape` (the seven cover shapes), `FirstLaunch`, `DoneBurst`, `AttentionTab`, `JellyTrio`, `DotWave`, `HomeBackdrop` (drift + night sky), `DrawnCheck`.
* C++ objects are QML singletons in the `Kisel.Core` module: `Hub`, `Prefs`, `Hooks`, `Chat`, `Vault`, `Shell`, `Displays`, `Sounds`, `Launcher`, `GitHub`.

## Safety rules (carried over from the brief)

1. Never block Claude Code (relay deadlines, silence on any doubt).
2. Never approve without an explicit click. *Always* is a click on a specific pattern: `Bash:<first two words>` for plain commands, the **exact** command when it contains `; | & $ ( ) < > \` or a newline, and `<tool>:<directory>` for edits. Rules are listed and clearable in Settings.
3. Never overwrite `settings.json` blindly: preview diff → dated backup → atomic write.
4. Secrets only in KWallet. No telemetry; the only network call is Anthropic, and only when the user chats.
5. Model output is rendered as plain text (no links, no markup).

## Windows

Everything outside `IslandWindow`, `Tray`, `Secrets`, `Sounds`, `Paths` and the relay's transport is the same code on both systems.

| Part | Plasma | Windows |
| --- | --- | --- |
| Transport | Unix socket `$XDG_RUNTIME_DIR/kisel.sock`, `SO_PEERCRED` on both ends | Named pipe `\\.\pipe\kisel-<user SID>` (`QLocalServer`, `UserAccessOption`: this user only). The relay checks that the process serving the pipe runs as the same user, because a pipe name can be taken by whoever creates it first. The app cannot ask the same of a relay that has already exited, so the pipe's access list is its whole check. |
| Relay I/O | non-blocking socket + `poll` | overlapped I/O, cancelled at the deadline |
| Relay location | `~/.local/share/kisel/bin/kisel-hook` | `%LOCALAPPDATA%\kisel\bin\kisel-hook.exe`, with `Qt6Core.dll` copied next to it (there is no system Qt). The hook command is written with forward slashes so it survives Git Bash, PowerShell and cmd. |
| Window | layer-shell overlay | topmost frameless tool window (no taskbar button, no Alt-Tab entry) |
| Click-through | input region = the island's shape (`setMask`) | A window region would clip the drawing too, so the whole window turns input-transparent (`Qt::WindowTransparentForInput`) while the pointer is outside the island's shape. A transparent window gets no pointer events, so a 30 Hz timer reads the cursor position and flips the flag. |
| Taskbar | drawn over panels (exclusive zone -1) | The taskbar is topmost too and wins, so "the output" is the work area (`QScreen::availableGeometry`): a dock on the taskbar's side sits against it. Settings has "Stay clear of the taskbar"; off, the whole monitor is used again. |
| Focus | keyboard interactivity `OnDemand` | `WS_EX_NOACTIVATE` unless a view needs keys; when that ends the keyboard goes back to the window it was taken from |
| Secrets | KWallet | Credential Manager, one generic credential per key (`Kisel/<name>`) |
| Tray | `KStatusNotifierItem` | `QSystemTrayIcon` |
| Sound | `paplay`, one process per sound | the WAV scaled to its volume in memory, then `PlaySound`: one sound at a time |
| Files | `~/.config/kisel`, `~/.local/share/kisel` | `%LOCALAPPDATA%\kisel` for both |

`kisel.exe` is a window-subsystem program; started from a terminal it borrows that console, so `--help` and the development flags still print.
