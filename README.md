Kisel это маленькая тёмная таблетка у края экрана, в которой сидят пять моти. Изначально она нужна была для одного: видеть, чем занят [Claude Code](https://claude.com/claude-code), не переключаясь в терминал, и отвечать на его «можно я запущу эту команду?» одним кликом. Потом в таблетку переехали плеер, уведомления, монитор железа и замер интернета, и теперь я её просто не закрываю.

Внутри нет ни одной картинки. Персонажи, иконки, искры, даже звуки сделаны кодом.

## Кто там сидит

| | Чем занята | Какая она |
| --- | --- | --- |
| **Miku** | Claude Code: сессии, разрешения, вопросы, чат | Старательная, напевает под нос. Шлёпнешь, надуется |
| **Rin** | Уведомления Windows: машет табличкой с названием программы | Шумная. От шлепка взрывается |
| **Luka** | Интернет: пинг, скорость, загрузки, замер | Спокойная. На шлепок смотрит как на идиота |
| **Zundamon** | Музыка из Spotify | Хвастун, но паникует первым |
| **Teto** | Процессор, видеокарта, память | Самодовольная, пока её не похвалишь |

Главную выбираешь кликом по скамейке справа. Остальные никуда не деваются: сидят рядом, моргают, иногда корчат рожи.

Кто чем занят, можно переставить в настройках: хоть Тето на Claude Code, хоть Мику на музыку. Характер и любимая еда остаются при персонаже, работа переходит.

## Таблетка

288 на 32 пикселя, живёт у любого края экрана. Что в ней показано, зависит от того, что сейчас происходит.

<p align="center">
  <img src="docs/img/bar.png" alt="Таблетка в разных состояниях" width="900">
</p>

Пара вещей, на которые ушло больше времени, чем стоило бы:

- На скамейку и обратно они летят сальто через всю таблетку. Просто исчезнуть было бы скучно.
- Пока Claude работает, Мику садится слева с его оранжевым зверьком в лапках, а рядом кто-нибудь составляет ей компанию. Они толкаются, перекидывают звёздочку, играют в прятки, тянутся к зверьку. Сценок больше сорока, и у каждой есть своя: над Тето смеются, и она замахивается метлой.
- Замер скорости и чистка памяти запускаются прямо из таблетки, и пока они идут, таблетка наполняется жидкостью.
- Если играет музыка и их хотя бы двое, время от времени начинается танец.
- Минуту ничего не происходит, и таблетка уезжает за край. Если играет музыка, остаётся мини-плеером, и по её краю можно перематывать трек.
- В полноэкранной игре она опускается к самому низу экрана, чтобы не висеть посреди картинки.
- Двигается кнопкой со стрелками в шапке карточки: она отлипает от края, идёт за курсором как желе, а когда отпустишь, сама летит к ближайшему краю.
- При запуске Мику выныривает снизу экрана, машет, и только потом появляется таблетка, в которую она улетает.

## Как поставить

Скачай `KiselSetup` со страницы [релизов](https://github.com/Tiutiunov/Kisel/releases/latest) и запусти. Ставится в профиль пользователя, права администратора не нужны. Нужна Windows 10 (1803+) или 11.

Установщик не подписан, сертификат стоит денег. Поэтому SmartScreen ругнётся: жми «Подробнее», потом «Выполнить в любом случае».

Обновляется сам. Раз в сутки спрашивает GitHub, не вышло ли чего, и если вышло, Рин поднимает табличку с номером версии. Дальше одна кнопка в настройках: скачает, сверит контрольную сумму, поставит и перезапустится. Проверку можно выключить там же.

Удаляется через «Приложения» в параметрах Windows. Хуки из настроек Claude Code при этом убираются, твои настройки остаются.

## Как подружить с Claude Code

Карточка → шестерёнка → **Connect Claude Code**. Kisel покажет, что именно допишет в `~/.claude/settings.json`, и не тронет файл, пока не нажмёшь. Перед записью делает копию.

Дальше Claude Code на каждое событие дёргает крошечную `kisel-hook`, а она передаёт его Киселю. Если Kisel не запущен, хук молча выходит и Claude Code ничего не замечает. Если хуки пропали или устарели после обновления, Kisel скажет об этом и предложит починить.

### Моды: чат и лимиты

Там же, в настройках, кнопка **Install mods**. Она ставит в Claude Code два плагина, которые идут вместе с Kisel:

- `kisel-prompts` связывает сессию с чатом Kisel: промпты туда, ответы и лимиты обратно.
- `cache-band` показывает над полем ввода в Claude Code, сколько токенов лежит в кеше.

Kisel для этого запускает родные команды `claude plugin ...` и показывает их заранее, так что нужен установленный `claude` в командной строке. Моды загружаются в сессиях, запущенных после установки.

## Discord

По желанию Kisel показывает в профиле Discord «Работает с Claude Code» с таймером. Выключено, пока не включишь в настройках. Название сессии показывается, только если включить и это. Общается он только с Discord на твоём компьютере.

## Про данные

Секреты (токен GitHub для виджета) лежат в диспетчере учётных данных Windows, в файлы не пишутся.

Телеметрии нет. В сеть Kisel ходит за виджетом GitHub, пингует `1.1.1.1` для Луки, раз в сутки проверяет обновления и по кнопке меряет скорость через Cloudflare. Всё это отключается или не запускается само. Чат идёт через твою локальную сессию Claude Code, а не через сеть Kisel.

Подробно, по пунктам: [docs/PRIVACY.md](docs/PRIVACY.md). Условия использования: [docs/TERMS.md](docs/TERMS.md).

Из уведомлений читается только название программы и количество. Текст не читается.

Настройки лежат в `%LOCALAPPDATA%\kisel\kisel.conf`, обычный текстовый файл.

## Собрать самому

Нужны Visual Studio 2022 с C++, CMake, Ninja и Qt 6.5+ для MSVC. Из «x64 Native Tools Command Prompt»:

```powershell
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=C:\Qt\6.10.3\msvc2022_64
cmake --build build
cmake --install build --prefix dist
dist\bin\kisel.exe
```

Установщик: `cmake --build build --target installer`.

Без Claude Code можно посмотреть так: `kisel.exe --demo` разыграет выдуманную сессию. `kisel.exe --speed-test` просто померит интернет и напечатает результат. Как всё устроено внутри, написано в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
